Golden Sun Recompiled
=====================

Native PC versions of Golden Sun (The Broken Seal) and Golden Sun: The Lost
Age, made from your own cartridge ROMs.

Starting
--------
Start GoldenSunLauncher (GoldenSunLauncher.exe on Windows) and click The
Broken Seal or The Lost Age. On first play, accept the preparation prompt and
choose your own matching USA/Europe ROM. Preparation happens once; later
selections start the game directly. New releases are offered before starting
either game.

On Linux you need a 64-bit system with SDL2 and OpenGL (both come with
SteamOS and most desktop distributions). If the launcher does not open,
install your distribution's SDL2 package (libsdl2-2.0-0 on Debian/Ubuntu,
sdl2 on Arch, SDL2 on Fedora).

Settings
--------
The gold cogwheel in the launcher, and F1 in the game.
Controls: use Controller and Alternate to bind the D-pad and stick together.
Hotkeys: bind Soft Reset to return to the current game's title screen. Soft
Reset keeps disk saves; unsaved progress is lost.

Music mods
----------
Recordings in the Music folder can replace the games' music. See
Music/README.txt.

Folders
-------
ROMs       Selected .gba files are copied here.
Saves      Saves and savestates. Existing matching .sav files and
           savestates are copied in; the originals are kept. Conflicting
           imports are kept in Saves/Imported.
Controls   Keyboard, controller and hotkey bindings, shared by both games.
Music      Music mods (optional).
games      Each game's engine, tools and other settings. Keep it beside the
           launcher.

This download contains no game code, ROM, BIOS or generated game library.
Everything from the games comes from your ROMs, on your computer.

Problems? Press F12 in the game right after it happens; the launcher packs a
bug report you can send with Send report.
