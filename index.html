What is this?Both games, one launcher

Golden Sun Recompiled turns the two Game Boy Advance games into programs that run straight on your PC. The games' own code is translated into PC code, so you get the same adventure with a wider screen, a proper settings menu and a handful of optional extras.

The Broken Seal

The first Golden Sun (2001). Isaac's journey, from Vale to the lighthouses.

The Lost Age

The second game (2002). Felix's side of the story, now in the collection too.

➤

Seamless: one long adventure

Turn on Seamless and the end of The Broken Seal runs straight into The Lost Age in the same window. Your clear data is saved, and The Lost Age loads it for you after you name Felix. Switch it on when you start a new game, in F1 → Game, or in the launcher.

You bring your own copy of each game. Nothing from the games comes with this project, and your game files are never changed.

Heads up: this is still being worked on. It's tested by playing through the games, and a few things may still look or sound slightly off.

Cheat menuBend the rules

Press F11 anywhere in either game (or the key you picked in the F1 menu). The game pauses and this window opens over the picture. Everything starts at normal. Try it: click the screen, then use the arrow keys (A or Enter switches On and Off).

Under the hoodHow it works

  • Real PC code. Each game's code is translated ahead of time, including the parts it loads while you play.
  • One shared engine. Both games run on the same engine, so a fix for one often helps the other.
  • No BIOS file. You only need your game files, not the handheld's start-up chip.
  • Checks your game files. The launcher makes sure each is the exact version this was built for.

FAQQuestions

How do I report a bug?
  1. Press F12 right after the problem shows up. The game keeps the last two seconds, so a flicker that's already gone is still caught. "BUG REPORT SAVED" appears in the top-right corner.
  2. Keep playing if you like, and press F12 again for any other problem.
  3. Close the game. A bug report window opens: write a few words about what happened and where, and press Send report. No account or form needed.

If the game crashes, the same window opens without you pressing F12. Nothing is ever sent unless you press Send report; otherwise the report stays on your computer in logs\bug_reports. A report holds the game's log and screen captures, your settings files and your Windows or Linux version, with your user name taken out. After a crash it also holds a snapshot of the game's memory. Only the developer sees it.

If sending doesn't work, the window offers the bug report form instead, where you can add the report by hand.

Is this an emulator?

No. The games' own code is translated into PC code ahead of time, so they run directly on your PC instead of through a program that imitates the Game Boy Advance.

Do I need my own copy of the games?

Yes. Nothing from Golden Sun comes with this project. In the launcher you pick The Broken Seal or The Lost Age and choose your own USA/Europe game file for it; it remembers each one and checks it's the exact version this was built for. You can play either game on its own. No BIOS file is needed.

Can I play a translation or a hack?

The launcher has a Skip the ROM check option for each game, which lets a different game file through. Only the original games are supported, so expect problems.

Why does the first start take a few minutes?

The first time you pick a game file, the game is prepared from it on your PC. A progress bar shows how far along it is. After that it starts straight away, until an update needs it to prepare again.

Where are my saves, and do they survive updates?

Your game files go in the ROMs folder and your saves and save states in the Saves folder, both next to the launcher. Saves from 0.4, which sat next to your game file, are brought over when you pick the same game file in the new version.

How do I update?

The launcher tells you when a new version is out and opens its download page. Unzip the new version into a new folder, start its launcher and pick the same game file. Your saves come along, and the game is prepared once more on the first start.

Can I play with a controller?

Yes. Every button can be changed in the F1 menu, for both keyboard and controller.

Is it finished?

Not yet. Test release 0.4 is out: download it from GitHub. Expect some rough edges, and please report what you find.

What does it run on, and what does it cost?

Windows 10 and 11, and a recent 64-bit Linux, for example Ubuntu 24.04, Debian 13, Fedora 40 or Arch, with SDL2 installed. It runs on the Steam Deck too. It's a free, noncommercial fan project.
