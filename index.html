What is this?

Golden Sun Recompiled turns the 2001 Game Boy Advance game into a program that runs straight on Windows (and, as a test, on Linux). It isn't an emulator. The game's own code is translated into PC code, so you get the same adventure with a wider screen, a proper settings menu and a handful of optional extras.

You bring your own copy of the game. Nothing from the game comes with this project, and your game file is never changed.

Heads up: this is still being worked on. It's tested by playing through the game, and a few things may still look or sound slightly off.

Game settings

The game's own Settings screen has a second page. Press Down past Auto-Sleep to reach it. Try it here: click the screen, then use the arrow keys or the buttons. The map that shows behind the menu in the game is left out.

Page one gains one choice too: Message Speed: Instant, which shows each line of dialogue at once.

Cheat menu

Press F11 anywhere (or the key you picked in the F1 menu). The game pauses and this window opens over the picture. Everything starts at normal. Try it: click the screen, then use the arrow keys (A or Enter switches On and Off).

Under the hood

  • Real PC code. The game's code is translated ahead of time, including the parts it loads while you play.
  • No BIOS file. You only need your game file, not the handheld's start-up chip.
  • Checks your game file. The launcher makes sure it's the exact version this was built for.

FAQ

How do I report a bug?
  1. Press F12 right after the problem shows up. The game keeps the last two seconds, so a flicker that's already gone is still caught. "BUG REPORT SAVED" appears in the top-right corner.
  2. Keep playing if you like, and press F12 again for any other problem.
  3. Close the game. A bug report window opens: write a few words about what happened and where, and press Send report. No account or form needed.

If the game crashes, the same window opens without you pressing F12. Nothing is ever sent unless you press Send report; otherwise the report stays on your computer in logs\bug_reports. A report holds the game's log and screen captures, your settings files and your Windows or Linux version, with your user name taken out. Only the developer sees it.

If sending doesn't work, the window offers the bug report form instead, where you can add the report by hand. On 0.1-test the launcher still uses that form.

Is this an emulator?

No. The game's own code is translated into PC code ahead of time, so it runs directly on your PC instead of through a program that imitates the Game Boy Advance.

Do I need my own copy of the game?

Yes. Nothing from Golden Sun comes with this project. You pick your own Golden Sun (USA/Europe) game file, and the launcher checks it's the exact version this was built for. No BIOS file is needed.

Why does the first start take a few minutes?

The first time you pick your game file, the game is prepared from it on your PC. A progress bar shows how far along it is. After that it starts straight away, until an update needs it to prepare again.

Where are my saves, and do they survive updates?

Your in-game save and your save states are stored next to your own game file, not in the program folder. Installing a new version doesn't touch them.

How do I update?

From 0.2 on, the launcher tells you when a new version is out and opens its download page. Unzip the new version, start its launcher and pick your game file. Your saves stay where they are, and the game is prepared once more on the first start.

Can I play with a controller?

Yes. Every button can be changed in the F1 menu, for both keyboard and controller.

Is it finished?

Not yet. Test release 0.2.1 is out: download it from GitHub. Expect some rough edges, and please report what you find.

What does it run on, and what does it cost?

Windows 10 and 11. New in 0.2 and still a test: a recent 64-bit Linux, for example Ubuntu 24.04, Debian 13, Fedora 40 or Arch, with SDL2 installed. It hasn't been tested on Steam Deck yet. It's a free, noncommercial fan project.
